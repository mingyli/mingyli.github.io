date: 2017-08-03

Let the set of probability questions be all math problems for which the answer is a probability. Then for all questions in this set the answer is a real number in $$[0, 1]$$. 

What is the cardinality of the set of probability questions? Since questions must have finite representations (English sentences, binary) the set of probability questions is countably infinite. But the set $$[0, 1]$$ is uncountably infinite; there does not exist a bijection between the set of all probabilities and the set of all probability questions.
